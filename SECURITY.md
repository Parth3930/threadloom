# Security Policy

## Supported Versions

Threadloom is currently in active development. We aim to provide security updates for the latest major/minor releases. 

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Threadloom, please report it privately. You can do this by using the **"Report a vulnerability"** feature in the GitHub Security Advisory tab of this repository, or by reaching out to the maintainers directly.

Please include the following information in your report:

- Description of the vulnerability.
- Steps to reproduce.
- Potential impact.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress.
